# i-Ship — Delivery & Shipment Management System

i-Ship is a logistics platform for managing customers, shipments, drivers, vehicles, delivery assignments, delivery attempts, proof of delivery, payments and public tracking.

| Part | Stack | Location |
| --- | --- | --- |
| Frontend | Angular 22, TypeScript, Tailwind CSS | [`frontend/`](frontend/) |
| Backend | Go, Gin, PostgreSQL | [`backend/`](backend/) |
| Infra | Docker Compose behind the existing Traefik | [`docker-compose.yml`](docker-compose.yml), [`docker/`](docker/) |

_Work in progress. Full documentation lives in [`docs/`](docs/)._
